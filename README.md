# 🖥️ System Health Monitor

A lightweight, beginner-friendly Python script to monitor basic system parameters like CPU cores and execution timestamps.

## 🚀 Features
- Checks total available CPU cores.
- Logs timestamps for system health audits.
- Clean and readable terminal output.

## 🛠️ How to Run
1. Make sure Python is installed.
2. Run the script:
   ```bash
   python monitor.py
